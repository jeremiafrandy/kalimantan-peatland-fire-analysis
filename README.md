# Kalimantan Peatland Fire Analysis

This repository contains analysis scripts, derived tables, and
supporting documentation for a multisource observational study
of antecedent rainfall, recorded fire-detection days, mapped
burned area, and supporting air-quality observations in
Kalimantan, Indonesia.

The analyses describe observational associations and spatial
contrasts. They do not establish causal effects, validated
fire forecasts, or source-specific community smoke exposure.

## Repository contents

The folder descriptions below correspond to the files included

## Data sources

Source datasets are identified in the source-file manifest
and the manuscript references. Files not redistributed here
must be obtained from their original providers.

Third-party data retain their original terms of use.

## Reproducing the analyses

Follow the analysis instructions supplied with the package.
Required input files, software dependencies, and execution
order should be checked before running the scripts.
